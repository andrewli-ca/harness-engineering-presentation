Slide 8 / 10

Steward’s self-learning system

Picks up your team’s conventions over time.

Real

Fix the code, push, reply that it’s fixed.

steward reply ↗
Fixed in a3f82c1 — updated the null check as suggested.
Noise

Reply explaining why this pattern is intentional.

steward reply ↗
Thanks — intentional. We prefer this pattern for performance reasons per AGENTS.md.
Hallucination

Reply pointing out what CodeRabbit got wrong.

steward reply ↗
This method is defined on line 42 — CodeRabbit missed the import from the shared package.
◆

Powered by Steward’s own eval system — every past classification is saved as a labeled example, and the most similar ones get pulled into context the next time a comment comes in. The more you use it, the closer its judgment gets to yours.

What Steward actually looks like

~/steward
steward/
├── bin/ 13 bash commands (one per action: push, watch, ship, …)
├── lib/ 2 helpers (common.sh + a small Python script for eval retrieval)
├── prompts/ 9 markdown prompts (classify, fix, reply, mr-description, …)
├── state/ per-MR JSON + .md (pending + executed actions)
└── evals/ labeled examples (Steward’s memory)
No frameworks. No SDKs. Just bash + prompts + Claude.
